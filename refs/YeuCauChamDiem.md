1. UI/UX của ứng dụng
    * Màn hình chính
    * Luồng người dùng
    * Cách bố trí chức năng
    * Trải nghiệm sử dụng
2. API / Model AI được áp dụng ở đâu
    * App gọi API nào
    * Dữ liệu lấy từ đâu
    * Nếu có AI thì model AI dùng cho chức năng nào
    * Kết quả AI được hiển thị/xử lý như thế nào trong app
3. CRUD và lưu trữ dữ liệu
    * Thêm, sửa, xóa, hiển thị dữ liệu ở đâu
    * Dữ liệu lưu local, firebase hay lưu qua API/database
    * Cách tổ chức dữ liệu trong app
4. Quản lý trạng thái
    * Nhóm dùng setState, Provider hay công cụ khác
    * Trạng thái được quản lý ở màn hình nào
    * Cách cập nhật giao diện khi dữ liệu thay đổi
5. Cấu trúc Clean Architecture
    * Cách chia thư mục
    * Tách UI, logic xử lý, model, service/repository
    * Giải thích luồng xử lý từ UI → xử lý logic → dữ liệu
